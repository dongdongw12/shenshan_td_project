# 《深山传家》美术圣经（Art Bible）· 明清木刻粗墨线 + 矿物重彩工笔

> 机器可读的唯一来源：[`pipeline/style/style_profile.json`](../../pipeline/style/style_profile.json)。本文解释每个参数的用意；改画风只改 profile，所有资产一起变。
> 单件资产只允许在 `assets_manifest.json` 里调：尺寸（高度 / 占地）、夜灯强度与高度、是否按占地限尺寸（`fit`）。

## 1. 画面总原则

1. **轮廓先行**：外轮廓是最粗的墨线，一眼读出“这是房子 / 这是箭楼”。再往里是细内线，最后才是色块。
2. **平涂 + 分染**：色块要平（Kuwahara 平涂抹掉 AI 贴图的斑驳），只在墨线附近做同色加深（工笔“分染”），不做照片式的连续渐变。
3. **暗部是冷色，不是灰色**：阴影 = 固有色 × 石青冷调，亮部 = 固有色 × 暖白。**禁止**灰蒙蒙、低对比的淡彩水墨。
4. **色阶化光影**：白昼 3 阶（受光 / 侧光 / 背光），阶与阶之间留窄柔边，像套色木刻分版。
5. **夜色靠灯，不靠月**：入夜整体压到夜靛，固有色减饱和；只有门窗、灯笼、火把附近出现暖橙，并带灯晕外溢。

## 2. 比例与镜头（全资产统一）

| 项 | 值 | 说明 |
|---|---|---|
| 地块 | 1 格 = 2m × 2m | `footprint: "2x2"` = 4m × 4m |
| 世界比例 | **128 px / m**（正式母版） | 所有精灵同一比例：墨线粗细一致，客户端不用逐张缩放 |
| 菱形 | 1 格 ≈ 362 × 181 px | 标准 2:1 等距（相机俯角 30°，方位角 45°） |
| 超采样 | ×2 渲染后 Lanczos 缩回 | 墨线边缘干净不锯齿 |
| 正面朝向 | 画面左下 | 建筑正面（glTF +Z / Blender −Y）；朝右下的版本由客户端水平镜像 |
| 尺寸适配 | 高度 = `target_height_m`，但整体不超出占地格的 96% | 树木等允许树冠出格的资产设 `"fit": "height"` |
| 锚点 | `_meta.json` 的 `anchor_px` | 占地中心落地点，客户端以此对齐格子 |

**包体提醒**：128 px/m 是母版精度（房子约 880×800、大院更大）。打图集时由 T3 按真机显示密度统一缩放（预计 0.5–0.75），母版保留在云盘便于以后出高清版。

## 3. 光源

| 光 | 方向 | 作用 |
|---|---|---|
| 白昼主光（暖阳） | 左前方来、高度角 50° | 正面亮、右侧面暗一阶、屋顶最亮；影子落在建筑**后方偏右**，不挡正面 |
| 白昼补光（天光） | 右侧、弱、冷蓝、不投影 | 让右侧暗面带一点冷调而不死黑 |
| 夜晚月光 | 左后方、弱、冷蓝、不投影 | 只勾一点轮廓 |
| 夜晚灯笼 | 正面偏左、暖橙、不投影 | 强度与高度在 manifest 的 `night_light` 逐件设定；箭楼在平台高度 |

> 原 v1 主光正好从相机方向打来（顺光），正面和侧面一样亮、没有体积感，v2 已改。

## 4. 色板（矿物颜料）

| 名称 | 色值 | 用途 |
|---|---|---|
| 蛎灰白 | `#ede3cc` | 石灰墙、山墙 |
| 黛瓦 / 瓦灰 | `#3e4552` / `#6b7482` | 屋面 / 屋脊、瓦当 |
| 青石 | `#7d8a8c` | 台基、台阶、山石 |
| 石青 / 二青 | `#2e5f8f` / `#5d8fb6` | 点缀（彩画、布幔）、暗部色调来源 |
| 石绿 / 二绿 / 松青 | `#3f8a63` / `#7fb98a` / `#24574a` | 植被、竹、松针 |
| 赭石 / 浅赭 / 檀褐 | `#9a5a35` / `#c88f5f` / `#5c3a26` | 木作、门板、树干、土地 |
| 朱砂 / 朱膘 | `#b8352a` / `#d9694a` | 柱子、灯笼、喜字——画面里最跳的颜色，控制用量 |
| 藤黄 / 草黄 | `#d9a838` / `#c9a66b` | 茅草、谷物、灯芯 |
| 墨 | `#1c1510` | 全部墨线（不是纯黑，带一点暖褐） |
| 夜靛 / 灯火 | `#1a2550`（夜空） / `#ff9a3c` | 夜晚环境与灯光 |

归色方式：Lab 空间向最近的若干色板色**软吸附**（`palette_strength` 0.45，只动色相/纯度，明度只动 15%），再整体提纯 1.25 倍。AI 贴图的颜色会被拉进这套色板，但保留原有的明暗细节。

## 5. 墨线层级（正式比例下的像素宽度）

| 层级 | 宽度 | 来源 | 说明 |
|---|---|---|---|
| 外轮廓 | 3.0 px，书法笔触最细处 50% | Blender Freestyle（轮廓、外轮廓、边界） | 笔触方向 60°，随走向粗细变化；0.5 px 手绘抖动 |
| 内结构线 | 1.25 px，80% 不透明 | 后处理：法线夹角 > 32° 或深度跳变 > 0.3m | 墙角、台基边、屋脊、柱子与墙的前后关系；自动去 AI 网格噪点 |
| 分染 | 墨线附近 5 px 内同色加深 22% | 后处理 | 工笔晕染感，白昼 22% / 夜晚 25% |

## 6. 地影

取白昼阴影接收面的透明度，涂成靛墨色 `#1f2740`、42% 不透明、轻微模糊；夜晚沿用同一形状、减到 60%。白昼与夜晚精灵轮廓、锚点完全一致，客户端交叉淡入淡出即可。

## 7. 不在精灵里做的事（交给客户端 T3）

- **宣纸纹理**：全屏叠加一层，避免每张精灵各带纹理在地图上拼出接缝（profile 里 `paper.enabled=false`）。
- **灯火闪烁、炊烟、飘雪**：用粒子/序列帧叠在精灵上，精灵本身保持静态。
- **入夜过渡**：白昼图 → 夜晚图透明度 0→1，配合全屏夜靛色调。

## 8. 资产自检清单

- [ ] 外轮廓连续、粗细有书法起伏；内线只出现在真实结构转折处，没有“毛刺”
- [ ] 色块平、无 AI 贴图斑驳；朱砂只出现在柱子/灯笼/喜字等少数位置
- [ ] 正面亮、右侧面暗一阶且偏冷；影子在建筑后方
- [ ] 夜晚：整体夜靛、暖光只在灯附近、有灯晕；没有粉紫色
- [ ] `_meta.json`：`px_per_meter` = 128（正式）、`fit_limited_by`、`anchor_px` 落在底面中心

## 9. 角色（敌人 / 村民）

- 管线：`make_characters.py` 程序化建模（基础几何体刚性绑定骨骼）+ 关键帧行走循环 → `bake_sprite_anim.py` 逐帧渲染，与建筑**同一套**相机、光照、墨线、风格化，保证画风一致。
- 造型：敦实、块面化（大头、粗短腿），一眼可辨：狼灰、野猪褐带獠牙、熊王巨大黑身红巾；土匪统一**红头巾 + 红腰带**，按兵种区分道具（刀 / 木盾 / 火把 / 斗笠 / 黑旗）。
- 朝向：只烘两个（front 面朝左下、back 面朝左上），朝右的两个由客户端水平镜像；8 帧行走、10fps，脚底中心为锚点。
- 夜晚：敌人身上没有灯，夜晚版由白昼版调成“月下夜靛”（约 60% 亮度），保证夜里依然看得清——这是可读性优先于写实的有意取舍。
- 外轮廓墨线比建筑细一档（×0.8），角色小，太粗会糊成一团；客户端显示时放大约 1.45 倍。
- 动作：行走（8 帧循环）+ 攻击（6 帧：野兽扑咬、土匪举刀劈砍、盾匪顶盾、当家的挥锄）；客户端在敌人砍建筑时自动切攻击并转向目标。家人另有“干活”（8 帧、8fps）：当家的双手抡锄刨地，阿莲 / 孩子弯腰插秧，走到稻田边时面朝田播放。导出用 `pipeline/atlas/export_chars.py`（合并进 `chars.json`，只增改烘过的角色）。
- 家人：当家的（斗笠、赭石短褐、锄头）、阿莲（石青衣裙、朱砂围裙、发髻）、孩子（石绿短衣、小一号）。白天在村里走动干活，夜里妻儿进屋、当家的守门挥锄——“攒钱娶妻生子”要在画面上看得见。
- 样张：`docs/art/samples/characters_walk_sheets.png`、`characters_attack_sheets.png`、`characters_villagers.png`、`demo_chars_night.jpg`、`demo_villagers_day.jpg`。

## 10. 地面与山石

- 地面由 `client/src/render/groundPainter.ts` 按地形图一次性画成离屏贴图（白昼 / 夜晚两张）：草地石绿平涂 + 墨色草簇、土路浅赭 + 路沿墨线、水田秧行 + 赭色田埂、溪水石青 + 木刻水纹 + 卵石岸。
- 山石格（不可走不可建）画成**青绿山水式石峰**：山顶石青 → 山腰石绿 → 山脚赭石的渐变、墨线轮廓、皴笔、苔点；靠谷地一侧矮、往外越来越高，由远到近叠画。
- 宣纸纹理由客户端全屏叠加（夜里自动减淡），不进精灵。

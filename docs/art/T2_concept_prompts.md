## 1. 为什么概念图不画黑描边

概念图只是喂给图生 3D（Hunyuan3D-2）的“正面参考”。最终的明清木刻粗墨线由 Blender Freestyle 在烘培时统一生成（2.6px、`#1c1510`）。概念图里有黑描边的话，Hunyuan3D-Paint 会把它当颜色涂进贴图，墨线就会糊、会重影。所以概念图要求：

- **平涂饱和矿物色块**（石青、石绿、赭石、朱砂、黛瓦深灰、蛎灰米白），**无描边、无水墨晕染**；
- **单个物体完整居中，纯白背景，无地面、无投影**（地面会被生成成一块底板，把高度归一化和占地都搞乱）；
- **正面偏右约 25° 的三分之四视角，略微俯视约 20°**。看到两个面有利于生成形体；偏角不超过 45°，笔记本才能自动把墙面转正到等距网格（转的是最小角度，所以正面会保持正面）；
- 造型**敦实、杆件粗**：细竹竿、镂空栏杆是图生 3D 的弱项。

## 4. 样张验收清单（用户确认后才量产其余 21 件）

**概念图**
- [ ] 物体完整、居中、白底、无地面；三分之四视角偏角 < 45°
- [ ] 无黑描边、色彩饱和不发灰

**`.glb`（看笔记本第 ⑦ 格体检图 / `raw_models/_debug/*_white.glb`）**
- [ ] 无漂浮碎块；屋顶坡面、屋脊起翘能看出来；箭楼四根柱子分得开（没有蹼状粘连）
- [ ] 俯视脚印的墙面与坐标轴平行（树除外）；正面朝 glTF +Z（体检图俯视的下边）
- [ ] 面数 ≤ 40k，`.gen.json` 记录了种子与偏航修正角

**烘培图（`baked_sprites/_preview/`，半比例 / 24spp；画风标准见 [ART_BIBLE.md](ART_BIBLE.md)）**
- [ ] 地块是标准 **2:1 菱形**（相机俯角 30°）；建筑正面在画面左下、侧面在右下
- [ ] 外轮廓墨线饱满有书法起伏；内线只在真实结构转折处，没有 AI 网格“毛刺”
- [ ] 色块平涂、颜色落在矿物色板里；正面亮、右侧面暗且偏冷，不发灰
- [ ] 夜晚夜靛 + 门窗/火把暖橙光与灯晕，没有粉紫色（松树无灯）
- [ ] 有单独的 `_shadow.png`；`_meta.json` 的 `px_per_meter` 一致、`fit_limited_by` 合理
- [ ] 用 `compose_preview.py` 摆进地块网格看：比例、锚点与旁边的替身/其他资产一致

**不达标时的调整顺序**：换概念图候选或种子 → 改提示词让形体更粗壮 → 改 `octree_resolution`（384→512 更细）→ 调 `assets_manifest.json` 的尺寸 / `night_light.energy`（画风参数只改 `style_profile.json`，全资产一起变） → 实在不行的件（多半是箭楼）改为 Blender 手工/程序化低模：`pipeline/blender/make_proxy_assets.py` 里已有 3 件替身可在此基础上细化。
